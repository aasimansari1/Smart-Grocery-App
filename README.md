## ✨ Features

- ✅ Add, edit, and check off grocery items
- 💡 Smart item suggestions as you type
- 💰 Budget tracker — set a limit and track spend
- 📂 Organize by category (Dairy, Vegetables, etc.)
- 💾 Saves list to localStorage

## 🚀 Getting Started

```bash
git clone https://github.com/aasimansari1/Smart-Grocery-App.git
cd Smart-Grocery-App
npm install && npm start
```
